# PuuChat – Cloud Chat Application

A cloud-connected mobile chat application prototype developed using MIT App Inventor.

## Overview

PuuChat is an experimental mobile application designed to explore basic messaging functionality using MIT App Inventor and CloudDB.

The application focuses on user identification, chat room interaction, and cloud-based message management.

## Features

- Username-based interaction
- Chat room joining
- Message input and display
- CloudDB integration
- Message management interface

## Technologies Used

- MIT App Inventor
- CloudDB
- Visual programming with blocks
- Android application development
